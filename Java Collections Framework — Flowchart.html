Overview

Framework / Collection

What is a framework?

A framework is a set of classes and interfaces that provide a ready-made architecture. A good object-oriented design can organize related classes into a framework where the classes perform related tasks.

Collections in Java / Collections Framework

The Java Collections Framework provides interfaces and classes to implement data structures and algorithms. It supports operations such as searching, sorting, insertion, manipulation, and deletion.

What is Collection in Java?

A Java Collection is a single unit of objects (a group). Common interfaces include Set, List, Queue, and Deque; common classes include ArrayList, Vector, LinkedList, PriorityQueue, HashSet, LinkedHashSet, and TreeSet.

LinkedList

What it is

LinkedList stores elements as nodes connected through links. Package: java.util.LinkedList. It uses a doubly linked list internally.

Characteristics

  • Dynamic memory allocation
  • Fast insertion and deletion
  • Slower random access
  • Allows duplicates
  • Implements List and Deque interfaces
  • Dynamic size - grows and shrinks automatically
  • Maintains insertion order
  • Allows null values
  • Index-based access is supported
  • Fast insertion/deletion at the beginning or end
  • Can be used as a List, Queue, or Deque

As a Queue - FIFO

Queue example

  public int compare(Student s1, Student s2) {

Generics

Generics

What are Generics?

Generics are parameterized types. A class, interface, or method that operates on a parameterized type is called generic. Examples include ArrayList<String> and ArrayList<Integer>.

Why do we need them?

  • Without generics a raw ArrayList can contain different types.
  • Wrong casts can produce ClassCastException at runtime.
  • Generics restrict the declared type and move wrong-type detection to compile time.
  • Generics reduce explicit casting and support code reusability.

Generic syntax

<T> returnType methodName(T value) {
  // method body
}

class Box<T> {
  T value;
}

interface Printer<T> {
  void print(T value);
}

Common type parameter names

TType
EElement
KKey
VValue
NNumber

Generic class

class Box<T> {
  T value;
  Box(T value) { this.value = value; }
  void display() { System.out.println("Value = " + value); }
}

Box<Integer> b1 = new Box<>(100);
Box<String> b2 = new Box<>("Hello");

Generic class with two type parameters

class Pair<K, V> {
  K key;
  V value;
  Pair(K key, V value) { this.key = key; this.value = value; }
}
Pair<Integer, String> p1 = new Pair<>(101, "Rahul");

Generic method

public static <T> void display(T value) {
  System.out.println(value);
}

display(100);
display("Hello");
display(25.5);
display('A');

Generic method returning a value

public static <T> T getValue(T value) { return value; }

int a = getValue(10);
String s = getValue("Java");
double d = getValue(25.5);

Generic method with two parameters

public static <T, U> void display(T first, U second) {
  System.out.println(first);
  System.out.println(second);
}

display(101, "Rahul");
display("Age", 25);

Generic interface

interface Printer<T> {
  void print(T value);
}

class Demo implements Printer<String> {
  public void print(String value) { System.out.println(value); }
}

Generic interface with two type parameters

interface Pair<K, V> {
  void display(K key, V value);
}

class Student implements Pair<Integer, String> {
  public void display(Integer key, String value) {
    System.out.println(key + " " + value);
  }
}

Generics in collections

  • ArrayList<String> names
  • ArrayList<Integer> numbers
  • HashSet<String> cities
  • HashMap<Integer, String> students

Optional

What it is

Optional is a container object that may or may not contain a value. It helps avoid NullPointerException by explicitly handling missing values. Package: java.util.Optional.

Methods + syntax

Function / MethodSyntaxPurpose / meaning
Optional.of()Optional.of("Rahul")Create an Optional containing a non-null value

Example

String name = null;
Optional<String> value = Optional.ofNullable(name);
System.out.println(value.orElse("Guest"));
if (value.isPresent())
  System.out.println(value.get());
else
  System.out.println("No Value Present");

If Optional is empty

Optional.empty() followed by ifPresent(...) produces no output when there is no value.

Advantages

  • Improves readability
  • Encourages safe coding practices
